# Board screenshots

Project screenshots for Build Board cards. Add yours in the same pull request
as your `data/builds.js` entry:

- PNG or JPG, roughly 800px wide (keep it under ~300 KB)
- name it after your project, e.g. `bracket-bites.png`
- set your entry's `shot` field to `"shots/bracket-bites.png"`

No screenshot? No problem — cards without one get a generated pattern.
